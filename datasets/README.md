# Benchmark datasets

This directory contains the benchmark datasets used in the FCHUIM experiments:

- Chess
- Connect
- Mushroom
- Accident
- Kosarak
- Chainstore

The datasets were obtained without modification from the SPMF dataset
repository:

[https://www.philippe-fournier-viger.com/spmf/index.php?link=datasets.php](https://www.philippe-fournier-viger.com/spmf/index.php?link=datasets.php)

Please cite the original data source and the SPMF library when using
these datasets.
